# whiteelephant-site

Site do app White Elephant / Amigo Ladrão, servido pelo GitHub Pages em
**https://whiteelephant.borzanti.com**.

| Caminho | O que é |
| --- | --- |
| `/` | Regras públicas em inglês (indexável, mira "white elephant rules") |
| `/regras/` | As mesmas regras em português |
| `/i/#<token>` | Página que abre o convite da festa |
| `/privacy/` | Política de privacidade (EN/PT) — URL a cadastrar na Play |

**Não edite aqui.** A fonte é `WhiteElephant/site/`; rode `site/publish.sh` lá.
A página `/i/` decodifica o formato de `share/InviteLink.kt` do app, e os dois
precisam mudar juntos.
